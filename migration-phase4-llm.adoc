=== Schritt 4.4: HTTP Interceptors

**Aufgabe:** Functional HTTP Interceptors für API Base URL, Loading State, und Error Handling

**Automatisierung:** 95%

**Prompt:**
[source]
----
Implementiere drei functional HTTP Interceptors (Angular 21+ Pattern):
1. API Interceptor: Fügt automatisch API Base URL zu relativen URLs hinzu
2. Loading Interceptor: Zeigt/versteckt Loading-Spinner während HTTP Requests
3. Error Interceptor: Globale Fehlerbehandlung mit Notification Service
----

**Dateien:**
- `src/app/core/interceptors/api.interceptor.ts`
- `src/app/core/interceptors/loading.interceptor.ts`
- `src/app/core/interceptors/error.interceptor.ts`

**API Interceptor:**
[source,typescript]
----
export const apiInterceptor: HttpInterceptorFn = (req, next) => {
  if (!req.url.startsWith('http')) {
    const apiReq = req.clone({
      url: `${environment.apiBaseUrl}${req.url}`
    });
    return next(apiReq);
  }
  return next(req);
};
----

**Loading Interceptor:**
[source,typescript]
----
export const loadingInterceptor: HttpInterceptorFn = (req, next) => {
  const loadingService = inject(LoadingService);
  loadingService.show();
  return next(req).pipe(
    finalize(() => loadingService.hide())
  );
};
----

**Error Interceptor:**
[source,typescript]
----
export const errorInterceptor: HttpInterceptorFn = (req, next) => {
  const notificationService = inject(NotificationService);
  return next(req).pipe(
    catchError((error: HttpErrorResponse) => {
      let errorMessage = 'Ein unbekannter Fehler ist aufgetreten';
      if (error.error instanceof ErrorEvent) {
        errorMessage = `Fehler: ${error.error.message}`;
      } else {
        errorMessage = error.error?.message || `Server Fehler: ${error.status}`;
      }
      notificationService.showError(errorMessage);
      return throwError(() => error);
    })
  );
};
----

**Hinweis:** Verwendung von Functional Interceptors statt klassenbasierten Interceptors (Angular 15+ Best Practice)

=== Schritt 4.5: Core Services

**Aufgabe:** NotificationService und LoadingService mit Angular Signals

**Automatisierung:** 95%

**Prompt:**
[source]
----
Implementiere zwei Core Services:
1. NotificationService: Wrapper für MatSnackBar mit Methoden für Success/Error/Info/Warning
2. LoadingService: Signal-basierter Loading State mit Counter für parallele Requests
----

**Dateien:**
- `src/app/core/services/notification.service.ts`
- `src/app/core/services/loading.service.ts`

**NotificationService:**
[source,typescript]
----
@Injectable({ providedIn: 'root' })
export class NotificationService {
  private snackBar = inject(MatSnackBar);

  showSuccess(message: string, action: string = 'OK') {
    this.snackBar.open(message, action, {
      duration: 5000,
      panelClass: ['snackbar-success']
    });
  }

  showError(message: string, action: string = 'OK') {
    this.snackBar.open(message, action, {
      duration: 7000,
      panelClass: ['snackbar-error']
    });
  }
}
----

**LoadingService mit Signals:**
[source,typescript]
----
@Injectable({ providedIn: 'root' })
export class LoadingService {
  public isLoading = signal<boolean>(false);
  private loadingCount = 0;

  show() {
    this.loadingCount++;
    this.isLoading.set(true);
  }

  hide() {
    this.loadingCount--;
    if (this.loadingCount <= 0) {
      this.loadingCount = 0;
      this.isLoading.set(false);
    }
  }
}
----

**Hinweis:** Signal-basierter State ermöglicht reaktives UI ohne RxJS Subscriptions

=== Schritt 4.7: Integration Testing & Theme Fix

**Aufgabe:** Angular Dev Server starten und Material 3 Theme Kompatibilität sicherstellen

**Automatisierung:** 80%

**Prompt:**
[source]
----
Starte Angular Dev Server und behebe Material Theme Fehler für Angular 21 Kompatibilität.
Angular 21 verwendet Material 3 (M3) Theme API.
----

**Problem:** Initial build failed mit "Undefined function: mat.define-palette()"

**Ursache:** Angular 21 + Material 21 verwendet Material 3 (M3) Theme API statt Legacy API

**Lösung:** Theme-Konfiguration auf M3 API migriert

**Vorher (Legacy API):**
[source,scss]
----
$notizblock-primary: mat.define-palette(mat.$indigo-palette);
$notizblock-accent: mat.define-palette(mat.$pink-palette);

$notizblock-theme: mat.define-light-theme((
  color: (
    primary: $notizblock-primary,
    accent: $notizblock-accent,
  )
));
----

**Nachher (M3 API):**
[source,scss]
----
$notizblock-theme: mat.define-theme((
  color: (
    theme-type: light,
    primary: mat.$blue-palette,
    tertiary: mat.$violet-palette,
  ),
));

html {
  @include mat.all-component-themes($notizblock-theme);
}
----
